# Air-Handwritten-Digit-Recognition
A real-time AI project that recognizes digits drawn in the air using your finger. Built with Python, TensorFlow, OpenCV, and MediaPipe — this system tracks hand motion, captures the drawn pattern, and predicts the digit using a CNN trained on the MNIST dataset.
# ✋ Air Digit Recognizer

A real-time **AI-powered system** that recognizes digits drawn in the air using your finger 🖐️.  
It combines **hand tracking (MediaPipe)**, **computer vision (OpenCV)**, and a **Convolutional Neural Network (CNN)** trained on the **MNIST** dataset.

---

## 🚀 Features
- 🎥 Real-time webcam input using OpenCV  
- 🤚 Hand & finger tracking using Google MediaPipe  
- 🧠 CNN trained on MNIST dataset (98%+ accuracy)  
- ✏️ Smooth finger drawing using motion smoothing  
- ⚡ Instant digit prediction and confidence display  
- 🔄 Press **C** to clear canvas, **Q** to quit  

---

- **TensorFlow / Keras**
- **OpenCV**
